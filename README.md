# Software-QA-Testing

## About This Repository

Welcome to my Software Quality Assurance Testing Portfolio

This repository contains practical QA documentation, testing examples, bug reports, test cases, testing reports, and learning notes based on my experience as a Software QA Engineer and my continuous learning in software testing.

The main purpose of this repository is to document my practical knowledge, demonstrate my understanding of software testing processes, and showcase the skills I have developed in Quality Assurance.

I worked as a Software QA Engineer, where I gained practical experience in software testing and quality assurance activities.

- Preparing and documenting test cases.
- Performing User Acceptance Testing (UAT).

- Communicating testing findings with Senior Testers.
- Participating in Agile software development activities.
- Understanding and following SDLC and STLC processes.
